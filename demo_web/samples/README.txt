No vehicle photographs are distributed with this source package.

Place your own authorized JPEG images in this folder:
  military.jpg
  diplomatic.jpg
  foreign.jpg

Alternatively copy ../demo.config.example.json to ../demo.config.json and
change the filenames under samples. All configured photos must remain inside
this samples folder. The UI labels describe the three selected examples;
they are not predicted plate classifications.

This entire folder is git-ignored except this README.txt. Do not force-add
real photos or runtime results when publishing the repository.
